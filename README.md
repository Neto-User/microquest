# MicroQuest Lab

Jogo de estudo de Microbiologia: 12 fases com personagens, fichas de resumo, quiz com som, estrelas, XP e desafio final.

É um único arquivo `index.html`, sem dependências. Para hospedar, basta publicar a pasta no GitHub Pages, Vercel ou Netlify.

## App (PWA)

Funciona como app no Android: abra o site no Chrome e toque em **Instalar app** (ou menu ⋮ → "Instalar app"). Depois de instalado, funciona offline.
